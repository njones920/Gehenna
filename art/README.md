# GEHENNA Art Direction

This directory preserves early visual references and gives future agents a shared target for concept art.

## Directory Layout

- `reference/` contains early generated reference images from the first public build period.
- `prompts/` contains reusable art-direction prompts and negative prompts.
- `research/` contains short historical visual notes for future art passes.
- `concepts/` is reserved for generated or curated concept art.

## Visual Thesis

GEHENNA should look like an ancient world remembering what was done to it, not like a conventional fantasy hellscape.

The strongest current visual anchors are:

- ritual sites as operational spaces: caves, thresholds, tombs, tells, dry wadis, ruined settlements, and watched roads
- material culture as interface: astragali, potsherds, oil lamps, clay seals, bronze, linen, ash, bone, water, blood, dust, and inscribed fragments
- the dead as specific people with history, obligation, grievance, and witness, not generic monsters
- power as configuration and consequence: circles, offerings, thresholds, names, timings, traces, and site memory
- public-world pressure: the same place has been changed by many practitioners before the current player arrives
- healable damage: scarring matters, but recovery, purification, testimony, and repair should be visible as future play
- Baal/Canaanite cult visual gravity: local worshippers, priests, kings, household ritual, food and drink offerings, altars, stelae, storm/fertility symbolism, and ordinary bodies under pressure

## Historical Grounding

Use Iron Age / Late Bronze Age southern Levant as the default visual gravity until the canon data layer broadens. Favor limestone, caves, terraces, olive oil lamps, simple textiles, clay vessels, bronze and iron fragments, field altars, tomb benches, sling stones, scarabs/seals where appropriate, and rough incised marks.

For people, prefer local Canaanite/Levantine dress cues over generic occult robes: tunics, wrapped cloaks, kilts or short skirts where appropriate, long robes, close caps or cloth head coverings, toggle pins/fibulae, belts, simple jewelry, and rank-specific ceremonial clothing.

Avoid treating the setting as medieval Europe, gothic horror, Dungeons & Dragons, or generic occult fantasy. The visual language should feel archaeological, bodily, local, and old.

## UI Direction

Player-facing UI should feel like a diegetic instrument: codex margins, site records, ritual autopsy notes, witness accounts, and pressure gauges. It can be clear and readable, but it should not become a modern spell hotbar or visible RPG stat sheet.

The current CLI is a serious prototype interface. Future graphical concepts should preserve the idea that the expression layer renders simulation truth; it does not decide the truth.

## Negative Prompt

Avoid horned demons, fire-and-brimstone spectacle, gothic cathedrals, medieval wizard robes, glowing spell hands, superhero poses, clean high-fantasy armor, generic skull piles, modern occult sigils, neon magic, purple-blue fantasy gradients, and UI that reads as a spellcasting action RPG.
